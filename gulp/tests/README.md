# ⚙️ Системные тесты Gulp

В этой папке хранятся тесты для логики сборщика и утилит обработки контента.

### Запуск:
`npm run test:run` (все тесты)

### Как добавить тест:
1. Создайте файл `имя-утилиты.test.js`.
2. Импортируйте тестируемую функцию из `../utils/`.
3. Опишите сценарии через `describe` и `it`.

Полная документация по тестированию находится в корневом файле [TESTING.md](../../TESTING.md).
