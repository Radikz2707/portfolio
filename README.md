# 🚀 Gulp + TypeScript Professional Template (v2.2)

Современный, быстрый и полностью автоматизированный шаблон для профессиональной модульной верстки. Построен на компонентном подходе (BEM) с использованием Gulp 5, Webpack 5, **TypeScript** и плоской конфигурации ESLint v10.

---

## 🚀 Быстрый старт (Развертывание нового проекта)

Чтобы начать новый проект на основе этого шаблона, выполните следующие команды в терминале:

1. **Клонируйте шаблон** в новую папку (точка в конце важна):
   ```bash
   git clone git@github.com:Radikz2707/gulp-template.git .
   ```

2. **Удалите связь с репозиторием шаблона**:
   ```bash
   rm -rf .git
   ```

3. **Установите зависимости** через стабильное зеркало с автоматическим разрешением конфликтов peer-зависимостей линтера:
   ```bash
   npm install --registry=https://npmmirror.com --legacy-peer-deps
   ```

4. **Инициализируйте структуру папок** (Header-Main-Footer):
   ```bash
   npm run init
   ```

5. **Запустите сервер разработки**:
   ```bash
   npm run dev
   ```

## 🛠 Команды проекта (npm run)

Все команды полностью автоматизированы и оптимизированы для работы на любых ОС (Windows, macOS, Linux).


| Команда | Описание |
| :--- | :--- |
| `npm run dev` | **Разработка:** Полная очистка `dist`, генерация шрифтов, быстрая сборка базы и старт сервера Browsersync за 1.2 сек. Включает вотчеры стилей, HTML и Webpack-слежение скриптов. |
| `npm run build` | **Финальный билд:** Глубокий кроссплатформенный линтинг, сжатие картинок, генерация WebP, минификация, вырезка неиспользуемого CSS (`purgecss`) и создание ZIP-архива с текущей датой. |
| `npm run lint` | **Контроль качества:** Ручная последовательная проверка всех **TS** (ESLint v10) и SCSS (Stylelint) файлов проекта на ошибки и соответствие БЭМ-структуре. |
| `npm run clean` | **Очистка:** Полное безопасное удаление папки `dist` перед новой чистой сборкой ресурсов. |
| `npm run update-modules` | **Обновление:** Интерактивный поиск и безопасное обновление всех npm-пакетов сборщика до актуальных версий. |

### 🧱 Конструктор компонентов и ленивых модулей

Больше не нужно вручную создавать файлы и прописывать импорты — используйте короткие команды автоматизации:

*   **Создать БЛОК (компонент страницы):**
    ```bash
    npm run create ---имя_блока
    ```
    *Генерирует HTML/SCSS/TS в `src/components/` и жестко подключает в точки входа. Идеально для каркаса сайта (например: `header`, `hero`, `services`).*

*   **Создать МОДУЛЬ (в ленивом асинхронном режиме):**
    ```bash
    npm run module ---имя_модуля
    ```
    *Генерирует SCSS/TS в папочной структуре `src/js/modules/` и подключает в `app.ts` через динамический `import()`. Код модуля подгрузится браузером автоматически только тогда, когда на странице появится элемент с соответствующим классом. Идеально для тяжелой логики (например: `slider`, `modals`, `tabs`).*

*   **Универсальное УДАЛЕНИЕ:**
    ```bash
    npm run remove ---имя_элемента
    ```
    *Универсальный деструктор. Физически удаляет папки/файлы (блока или модуля) и полностью, бесследно вырезает все регулярные выражения импортов, вызовов и асинхронных блоков из файлов проекта, не ломая форматирование.*

## ⚙️ Технологические особенности

### 💎 Качество кода и Линтинг
*   **TypeScript Strict**: Полная поддержка компиляции, строгая проверка типов (`strict: true`) и изоляция модулей (`isolatedModules`) для бесперебойной работы с Webpack.
*   **Modern ESLint & Stylelint**: Проверка и автоисправление (`--fix`) измененного файла происходят за доли секунды прямо при сохранении файла, выводя цветные отчеты в консоль.
*   **Sass @use**: Современная модульная система стилей без использования устаревшего и хрупкого `@import`.
*   **Сортировка свойств**: Настроена строгая логическая группировка CSS-свойств в Stylelint (от позиционирования и размеров к визуалу и анимациям) для идеальной структуры стилей.

### 🖼 Работа с графикой и шрифтами
*   **Smart WebP Cache**: Автоматическая генерация `.webp`. Плагин `newer` сопоставляет базовые имена файлов, благодаря чему картинки не пережимаются заново при перезапуске сервера.
*   **SVG Спрайты**: Нативная и безопасная очистка иконок от лишних атрибутов через встроенный SVGO-трансформатор прямо во время сборки в спрайт.
*   **PWA Favicons**: Защищенный таск автоматической генерации полного адаптивного набора иконок (Apple, Android, браузеры) и манифестов из одного файла `favicon.png`.
*   **Авто-шрифты**: Сборщик автоматически конвертирует исходные `.ttf`/`.otf` файлы в облегченный формат `.woff2` и сам генерирует файл подключения `_fonts.scss` со всеми начертаниями.

## 🏗 Архитектура и TypeScript Aliases

Для чистых импортов без бесконечных цепочек `../../` настроены системные алиасы путей в `tsconfig.json` и Webpack:
*   `@/*` — указывает на корень скриптов `src/js/`
*   `@comp/*` — указывает на папку компонентов `src/components/`
*   `@modules/*` — указывает на папку логических модулей `src/js/modules/`
*   `@plugins/*` — папка `src/js/plugins/` для кастомных локальных библиотек, которых нет в репозитории NPM.

### 💎 Качество кода и Автоматизация

- **Modern PostCSS & Autoprefixer**: Медиа-запросы автоматически группируются и сортируются по принципу Mobile-First с помощью `postcss-sort-media-queries`, не нарушая современные CSS-сетки.
- **Pre-commit хуки (Husky + lint-staged)**: Полная автоматизация контроля качества. При каждой команде `git commit` система автоматически запускает Stylelint за доли секунды, проверяет измененные файлы и сама выстраивает CSS-свойства в идеальный логический порядок перед отправкой на сервер.
- **Node.js LTS Protection**: В конфигурации проекта жестко зафиксирована минимальная версия Node.js (`>=24.0.0`), что гарантирует стабильную сборку и защиту от конфликтов зависимостей (EBADENGINE).
